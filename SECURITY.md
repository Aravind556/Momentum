# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through [GitHub security advisories](https://github.com/Aravind556/Momentum/security/advisories/new) and include:
- what the issue is and where it is (file, endpoint or page);
- steps to reproduce, or a proof of concept;
- the impact you think it has.

You can expect an acknowledgement within a few days. Once a fix is released, you'll be credited in the release notes unless you'd rather stay anonymous.

## Scope

In scope: the code in this repository (API, web app, Docker setup).
Out of scope: third-party services (Neon, LeetCode, Codeforces, email providers) and attacks that need physical access to a user's device.
